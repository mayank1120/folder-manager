# OrganizeApp

A native macOS SwiftUI app for the Organize file management engine.

## Requirements

- **macOS 14.0+** (uses `@Observable` macro)
- Xcode 15.0+
- Swift 5.9+

## Setup

### Creating the Xcode Project

1. **Open Xcode** → File → New → Project
2. **Select**: macOS → App
3. **Configure**:
   - Product Name: `OrganizeApp`
   - Team: Your development team
   - Organization Identifier: `com.yourname`
   - Interface: SwiftUI
   - Language: Swift
   - Storage: None
   
4. **Save** in a temporary location

5. **Add OrganizeCore Package**:
   - File → Add Packages → Add Local...
   - Select the `folder_manager` directory (parent of OrganizeApp)
   - Add the package to the app target

6. **Replace files**:
   - Delete the default `ContentView.swift` generated by Xcode
   - Drag all files from this `OrganizeApp/` directory into the Xcode project
   - Replace the entitlements with `OrganizeApp.entitlements`

7. **Build and Run** (⌘R)

## Features

- **Project Management**: Create, delete, and switch between projects
- **Source Selection**: Drag-drop folders or browse via file picker
- **People Configuration**: Add people with keyword tokens for file routing
- **Scan & Plan**: Scan sources and generate deterministic execution plans
- **Preview**: View operations, needs-review items, and excluded files in tabs
- **Apply**: Execute plan with progress tracking
- **Verify**: Confirm all operations completed successfully
- **Delete Originals**: Remove source files (with confirmation dialog)
- **Rollback**: Reverse applied operations
- **Stale Bookmark Relink**: UI to restore access when folder paths change

## Sandbox & Permissions

The app uses these entitlements:
- `com.apple.security.app-sandbox` — App sandbox enabled
- `com.apple.security.files.user-selected.read-write` — Read/write user-selected files
- `com.apple.security.files.bookmarks.app-scope` — Persist security-scoped bookmarks

## Note on Plan Items

The PreviewView shows three categories of plan items:
1. **Move Eligible**: Items that will be moved/copied (from `plan_operations`)
2. **Needs Review**: Items requiring manual attention (from `plan_items` with disposition `NeedsReview`)
3. **Excluded**: Items excluded by policy (from `plan_items` with disposition `ExcludedByPolicy`)
 
`OrganizeCore` provides `PlanStore.fetchPlanItemRows(planId:disposition:)` to load NeedsReview/Excluded rows for the UI.
